# 🔮 내 운세 지금은 (지금 이 순간 나의 기세)

> **20~40대 직장인을 위한 초단위 동적 운세 & 기세 분석 웹 플랫폼**  
> 모바일 최적화 (Mobile-First) | 추가 비용 0원 | 100% 브라우저 기반 구동

---

## 📂 폴더 파일 구성

- **`index.html`** : 웹사이트 전체가 담긴 메인 단일 파일 (HTML + Tailwind CSS + FontAwesome + 인터랙티브 JS 로직 내장)
- **`사이트_테스트_실행.command`** : 맥(Mac)에서 더블클릭 한 번으로 내 브라우저에서 사이트를 즉시 띄워보는 로컬 테스트 실행 파일
- **`사이트_원클릭_자동배포.command`** : 파일 수정 후 더블클릭 한 번으로 깃허브에 올리고 렌더(Render)를 통해 1분 만에 전세계에 자동 배포하는 실행 파일
- **`README.md`** : 사이트 구조, 배너 광고 연동 및 무료 배포 가이드 문서

## ✨ 핵심 반영 기능 (완료)

1. **마름모꼴(삼각) 0~100점 대칭 분포 알고리즘**
   - 두 개의 독립 균일 난수를 결합하여 **중앙(50점 근처) 확률이 가장 높고, 0점과 100점은 희귀하게 출현**하는 마름모꼴(◇) 분포 완벽 적용.
2. **점수대별 4단계 맞춤 운세 시스템**
   - **0~9점 (극단적 주의 구간)**:
     - ⚠️ 주의사항과 지시사항 대폭 증가 (긴급 지시사항 4계명 / 생존 모드 행동 수칙)
     - 기세 별점 1개 (★☆☆☆☆☆☆☆☆☆), 스텔스 방어 운세
   - **10~50점 (좋지 않은 운세 구간)**:
     - 걱정/주의 위주의 상세 운세 및 행동 요령
     - 기세 별점 2~5개, 칼퇴 성공률 48~71%
   - **51~89점 (상승 곡선 구간)**:
     - 점수가 높아질수록 좋은 내용 반영 (51~69점: 평온·안정, 70~89점: 호조·인정)
     - 기세 별점 6~8개, 칼퇴 성공률 75~92%
   - **90~100점 (대길 최고조 구간)**:
     - 기세등등, 압도적 성공, 전폭적 지지 등 좋은 내용 위주 구성
     - 기세 별점 9~10개, 칼퇴 성공률 95~100%, 골드빛 텍스트 효과
3. **🍀 행운의 숫자 (1~111 랜덤)**
   - 기존 '탕진 방어' 항목을 '행운의 숫자'로 교체하여 매 회차마다 1부터 111 사이의 고유한 행운 번호 부여.
4. **동적 아날로그 시계 & 3초 인물/배경 스캐닝 연출**
   - 실시간 시계 초침 스핀 연출 + 스마트폰 카메라/앨범 사진 3초 가상 AI 오라 스캐닝.
5. **행운의 컬러 칩 & 주변 인물 주의사항 & 바이럴 공유**
   - 원형 컬러 칩 도형(●), 오른쪽/왼쪽/정면 인물과의 관계 팁, 카카오톡 공유 문구 자동 생성.

## 💰 다음 단계 ① : 배너 광고(수익화) 연동 안내

수익화를 위해 **Google AdSense** 또는 **카카오 애드핏(Kakao AdFit)**을 연동할 수 있도록 `index.html` 내부에 전용 슬롯을 마련해 두었습니다.

### 1) 카카오 애드핏 (Kakao AdFit - 심사가 빠르고 국내 서비스에 최적)
1. [Kakao AdFit 관리자센터](https://adfit.kakao.com)에 로그인합니다.
2. [광고관리] > [새 매체 등록]에서 웹사이트 주소를 등록합니다.
3. 광고 단위 생성:
   - **상단 배너**: 모바일 띠배너 (320x50)
   - **하단 배너**: 모바일 직사각형 (300x250)
4. 발급된 `<ins class="kakao_ad_area" ...></ins><script src="..."></script>` 스크립트를 복사하여 `index.html`의 각 광고 주석 위치에 넣으시면 됩니다.

### 2) 구글 애드센스 (Google AdSense)
1. [Google AdSense](https://adsense.google.com)에 사이트 주소를 등록하고 승인을 받습니다.
2. [광고 단위 기준] > [디스플레이 광고] 생성 (반응형 또는 고정 크기).
3. 발급된 광고 코드를 복사하여 `index.html` 내 광고 영역에 삽입합니다.

## 🚀 다음 단계 ② : GitHub & Render 연동을 통한 무료 배포 매뉴얼

비개발자분도 무료로 전세계에 사이트를 공개할 수 있는 가장 쉬운 방법입니다. (서버 유지비 0원)

```mermaid
flowchart LR
    Local[내 맥북에서 사이트 수정] -->|사이트_원클릭_자동배포.command 더블클릭| Git[GitHub 저장소]
    Git -->|Webhook 자동 감지| Render[Render 무료 호스팅]
    Render -->|1분 후 자동 반영| Live[실제 내 도메인 사이트]
```

### [단계 1] 깃허브(GitHub) 저장소 준비
1. [GitHub](https://github.com)에 접속하여 로그인합니다.
2. 우측 상단 **[+]** > **[New repository]**를 클릭합니다.
3. **Repository name**에 `my-fortune-now` (원하는 영문 이름)를 입력합니다.
4. **Public** 선택 후 하단의 녹색 **[Create repository]** 버튼을 클릭합니다.

### [단계 2] 렌더(Render) 무료 호스팅 연동
1. [Render](https://render.com)에 접속하여 무료 회원가입(GitHub 계정으로 로그인 권장)을 진행합니다.
2. 대시보드 우측 상단 **[New +]** 버튼 > **[Static Site]**를 클릭합니다.
3. 방금 만든 GitHub 저장소(`my-fortune-now`)를 찾아 **[Connect]** 버튼을 클릭합니다.
4. 설정 입력 (매우 간단합니다):
   - **Name**: `my-fortune-now` (원하는 사이트 주소명)
   - **Branch**: `main`
   - **Root Directory**: `지금 이 순간 나의 기세`
   - **Build Command**: (비워둠)
   - **Publish Directory**: `.`
5. 하단의 **[Create Static Site]** 버튼을 클릭합니다.
6. 약 1분 후 `https://my-fortune-now.onrender.com` 과 같은 무료 보안 접속(HTTPS) 링크가 발급됩니다!

### [단계 3] 일상적인 업데이트 방법
* 앞으로 `index.html` 내용이나 광고 코드를 수정한 뒤,
* `지금 이 순간 나의 기세` 폴더 안의 **`사이트_원클릭_자동배포.command`** 파일만 더블클릭하시면 컴퓨터가 알아서 깃허브에 전송하고 렌더 사이트를 1분 내로 최신 상태로 자동 업데이트해 줍니다!
